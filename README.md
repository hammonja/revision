# Revision

A Python webserver for a GCSE revision timetable.

## Run

```powershell
pip install -r requirements.txt
python app.py
```

Then open:

```text
http://127.0.0.1:3000
```

Pages available now:

- `/revision`
- `/exams`
- `/subjects` for subjects and topic progress
- `/planner` for day-plan setup and revision-slot population
- `/settings` for exam timetable upload, exam parsing, and subject auto-allocation
